# CabinModSettings 0.1.0

> 🛟 **Need help or found a bug?** Get support at [support.doodesch.de/modsettings](https://support.doodesch.de/modsettings).

Adds a **Mods** card with separate **Settings** and **Info** windows. Adjust supported mods with native buttons and sliders, Apply, Cancel and Defaults. View installed versions and support links in Info.

Requires [UE4SS 3.0.1 or later](https://www.nexusmods.com/thecabingame/mods/4).
